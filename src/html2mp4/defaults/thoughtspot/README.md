# Built-in brand: ThoughtSpot

This folder is the brand a fresh install starts with (colours, dark and light logos, design rules, pronunciations and the
Geist / Geist Mono typefaces). Change or replace it any time in **Settings > Brand kit**; **Reset** returns to it.

- `brand.json`: brand settings and default pronunciations. No keys or personal data.
- `fonts/`: Geist and Geist Mono, © The Geist Authors, licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
- The ThoughtSpot name and logos are trademarks of ThoughtSpot, Inc., from its external-use brand kit. They are included here
  as the default look for ThoughtSpot training modules; they are not covered by this project's MIT licence.

Set `HTML2MP4_BRAND=neutral` to start from the plain neutral brand instead.
